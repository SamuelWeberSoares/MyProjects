# Finax - Design Branco

Uma versão moderna e elegante do site da Finax com design branco, transparente e minimalista.

## 🎨 Características do Design

- **Paleta de Cores Moderna**: Uso de tons de azul, branco e cinza
- **Efeitos Glassmorphism**: Elementos com transparência e blur
- **Animações Suaves**: Transições e animações elegantes
- **Design Responsivo**: Adaptável a todos os dispositivos
- **Performance Otimizada**: Carregamento rápido e eficiente

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estrutura semântica e acessível
- **CSS3**: Estilos modernos com CSS Grid e Flexbox
- **JavaScript**: Interatividade e animações
- **Google Fonts**: Tipografia Inter para melhor legibilidade

## 📋 Funcionalidades

### ✨ Animações e Interatividade
- Smooth scrolling entre seções
- Animações de entrada para elementos
- Contadores animados para estatísticas
- Efeitos de parallax suave
- Círculos flutuantes animados
- Hover effects em cards

### 🎯 Seções do Site
- **Header**: Navegação fixa com efeito blur
- **Hero**: Seção principal com chamada para ação
- **Estatísticas**: Números impressionantes com animação
- **Sobre**: Informações sobre a empresa
- **Serviços**: Cards dos principais serviços
- **Depoimentos**: Feedback dos clientes
- **CTA**: Chamada para ação final
- **Footer**: Informações de contato e links

### 📱 Responsividade
- Layout adaptável para desktop, tablet e mobile
- Menu mobile otimizado
- Imagens e textos responsivos
- Botões e formulários adaptáveis

## 🚀 Como Usar

1. **Baixe os arquivos**: 
   - `index.html`
   - `styles.css`
   - `script.js`

2. **Abra o arquivo `index.html`** em seu navegador

3. **Personalize conforme necessário**:
   - Altere cores no arquivo CSS
   - Modifique textos no HTML
   - Ajuste animações no JavaScript

## 🛠️ Personalização

### Mudando as Cores
```css
/* No arquivo styles.css */
:root {
    --primary-color: #sua-cor-aqui;
    --secondary-color: #sua-cor-aqui;
}
```

### Adicionando Novas Seções
```html
<!-- No arquivo index.html -->
<section class="nova-secao">
    <div class="container">
        <!-- Seu conteúdo aqui -->
    </div>
</section>
```

### Customizando Animações
```javascript
// No arquivo script.js
// Modifique os valores de duração e easing
element.style.transition = 'all 0.5s ease';
```
